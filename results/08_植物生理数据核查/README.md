# 回填主表与燕麦生理数据核查

## 主表核查

- 唯一主表共有69个已确认田间小区记录，`田间小区唯一ID`为69个不同值。
- 15个主分析测序样品均映射到唯一的`PlotRecordID`，每个处理3个记录。
- 用户已确认`T1-1/T1-2/T1-3`等是正式田间随机排列号；派生元数据已按此状态更新。
- 主表已经用`T1-1…T1-3`、`T6-1…T6-3`等标签替代原来的处理级占位符。
- 当前主表没有独立的“田间区组/Block”字段。
- 主表源文本仍写着“真实随机排列ID待核对”，但这是文字未刷新；正式随机号
  已由用户确认，派生表`sample_sheet.csv`已写为“已确认”。

## 燕麦生理数据

`数据/燕麦生理指标.xlsx`包含12个处理：

`T1, T5, T6, T7, T8, T12, T13, T14, T15, T19, T20, T21`

其中与论文2主分析的人工处理重叠的是：

| 论文2处理 | 燕麦处理 | 密度 |
| --- | --- | --- |
| As | T1 | 高 |
| AFP | T6 | 高 |
| AEFP | T7 | 高 |
| BP | 无 | 不适用 |
| Natural | 无 | 参照 |

高密度三组的处理级描述值：

| 处理 | 5株总干重 | 10株湿重均值 | 10株高度均值 |
| --- | ---: | ---: | ---: |
| T1/As | 27.5 | 16.82 | 129.2 |
| T6/AFP | 32.8 | 17.51 | 132.1 |
| T7/AEFP | 39.8 | 18.80 | 146.8 |

T7在三项处理级指标中均为数值最高值。但每个处理只有一个处理级汇总行，
没有`T1-1/T1-2/T1-3`等小区重复，不能执行植物指标与微生物指标的小区级相关。

## 已排除的用法

- `重量!B2:B13`的“5株总干重”是处理级汇总值，不是3个小区重复。
- `重量`工作表没有给出干重和湿重的单位，当前只保留原始数值，不写g或kg。
- `重量!D2:M13`与`高度!B2:K13`中的10株是植株子样本，不是独立小区重复。
- `高度!A32:G55`内置的单因素方差分析把10株当作重复，不能作为处理效应的
  推断证据，本分析不复用其中的P值。
- `Sheet1!A2:D11`仅有P1的10株根长、根重和茎重，无法对应本研究的处理或小区，
  不并入主表。
