- `T1-1/T1-2/T1-3`等编号是正式田间随机排列号，而不是处理内序号。

- 田块1–5虽未显示在更新图中，但已由用户确认：
  `T1-2`、`T12-2`、`T9-3`、`T2-2`、`T6-1`。
- 这5个编号与2019年随机表全部一致。至此T1–T22共66个随机田块全部确认，

  `T1-2`和`T6-1`有确认田块号但图中未显示单元格。

## 配方区块说明

- 图左侧另有8个`p`配方区块。其中6个播种量可精确匹配T5、T14、T11、T6、
  T13、T12；`p22`和`p23`为四物种配方，不对应主处理表T1–T21。
- 这些`p`区块是否属于盆栽/配方示意层，还是另5个田间位置的最新表达，仍需
  用户确认；当前不把它们当作田间位置写回。

## 文件

- `layout_cells_69.csv`：8个配方区块、16个中部田块和45个东南田块。
- `field_positions_61.csv`：已与随机表对应的61个田块位置。
- `randomized_plots_66.csv`：66个已确认随机田块及其图示单元格状态。
- `plots_without_diagram_cell.csv`：已确认编号但图中未显示的田块1–5。
- `user_confirmed_plot_assignments.csv`：用户提供的处理与田块号核对表。
- `sample_position_link.csv`：18个测序样品的位置连接状态。
- `layout_abbreviation_dictionary.csv`：所有简称到处理代码的字典。
- `layout_unresolved.csv`：`p22`、`p23`配方区块的未决记录。
- `layout_audit.json`：位置数量、简称匹配和未决项摘要。
