# 土壤养分样品核查

## 样品身份

依据`数据/原始数据/土壤养分结果.docx`和用户确认：

- 土壤22、22-2：当年未建植人工裸斑，对应论文处理T22。
- 土壤23：实验地块边道路土，长期无植被覆盖；属于实验外参照，不属于T22。
- 土壤24：天然参照，对应论文处理T23和原始测序组24。
- 土壤25：当前身份未确认，不进入主分析。

## 论文2可连接土壤样品

| 处理 | 土壤样品 |
| --- | --- |
| As/T1 | 1 |
| AFP/T6 | 6、6-2 |
| AEFP/T7 | 7 |

这些土壤结果是**处理级观测**。主表虽然把它们连接到3个测序样品行，但不表示
每个土壤值来自对应的测序小区，不能据此构成3个独立土壤重复。

## 数据提取

- 从DOCX四张表提取28个土壤样品ID、9项指标，共252条长表记录。
- `3-2`、`6-2`、`22-2`保留为独立原始样品ID，不自动合并或取平均。
- 土壤23的碱解氮原值`69.7（150）`存在歧义，保留`RawValue`并将
  `NumericValue`置空，未擅自选择69.7或150。

## 文件

- `soil_nutrients_long.csv`：全部DOCX土壤指标的机器可读长表。
- `soil_sample_identity.csv`：28个土壤样品的身份与论文2用途。
- `paper2_soil_observations.csv`：与论文2五个主处理有关的土壤观测。
- `external_roadside_bare_soil23.csv`：实验外道路裸土参照。
- `soil_value_ambiguities.csv`：保留而未解析的原始歧义值。
- `soil_audit.json`：数量、身份和歧义摘要。
