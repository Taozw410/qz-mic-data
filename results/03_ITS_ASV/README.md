# ITS ASV 分析

## 运行参数

- 输入：18 个供应商已拼接的 `trim` FASTQ。
- DADA2：单端模式，`truncLen=0`，`maxEE=3`，`truncQ=0`，`minLen=50`。
- 误差模型：`nbases=1e7`，`MAX_CONSIST=2`，随机种子 `20261023`。
- 嵌合体去除：`removeBimeraDenovo(method="consensus")`。
- 主分析：论文五组共 15 个样品。
- 敏感性分析：额外纳入未分配的原始组 23，共 18 个样品。
- 抽平深度：主分析和敏感性分析均为 49,234 条非嵌合序列；这是五组数据的最小样品深度。

## 数据质量

- 过滤后保留率为 94.5%–99.0%。
- 去噪后每样品保留约 4.9–7.2 万条序列。
- 共保留 2,481 个 ASV。
- 嵌合体去除后保留率为 92.5%–100%。

## 主要结果

- α多样性：Observed P=0.152，Shannon P=0.800，Simpson P=0.899。
- β多样性：ASV Bray-Curtis PERMANOVA R²=0.469，P=0.0002。
- β离散度：P=0.762，未发现显著的组间离散度差异。
- Aitchison：R²=0.444，P=0.0001。
- 纳入原始组23后，Bray-Curtis R²=0.490，P=0.0001。

各人工处理到天然参照的 ASV Bray-Curtis 距离：

| 处理 | 平均距离 | SE |
|---|---:|---:|
| AEFP | 0.615 | 0.016 |
| As | 0.652 | 0.020 |
| BP | 0.658 | 0.025 |
| AFP | 0.667 | 0.074 |

AEFP 在四个人工处理中观测平均距离最小，但差距小于组内变异，不能表述为
“已经恢复为天然群落”。补充的分层 bootstrap、精确标签置换和逐样品剔除见
`../06_稳定性与参照区间/`：AEFP 只是描述性最接近，当前3个重复不足以确认
组间排序，且剔除 AFP 的 `20_3` 后 AEFP 降为第二。
